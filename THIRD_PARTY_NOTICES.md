## BeatNetLite

The experimental audio-analysis workflow downloads BeatNetLite at runtime into the Codespace user's cache. The source code and pretrained weights are from [turbo/BeatNetLite](https://github.com/turbo/BeatNetLite), pinned to commit `90828feb6cf9bc7564e5d5fa37bc1b240119e1a2`. The upstream repository identifies its license as Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/.

BeatNetLite is used for beat, downbeat, tempo, and beats-per-bar estimation. The time-signature denominator shown by this project is a common-meter mapping and can need manual correction.
